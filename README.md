# NOCK — Money, with proof.

A static, responsive introduction to NOCK and its monetary thesis. Near-black surfaces, warm white typography, and luminous gold graphics. Plain HTML, CSS, and JavaScript; no dependencies, build step, accounts, or external APIs. The diagrams are original SVG, CSS, and Canvas; the N mark and favicon are original assets from nockchain.org. Google Fonts supplies Manrope and Instrument Serif, with local fallback fonts.

## Preview

From this directory, run `python3 -m http.server 4173 --bind 127.0.0.1`, then visit `http://127.0.0.1:4173`.

Deploy `index.html`, `styles.css`, `script.js`, and `assets/` together on any static host. No rewrite rules are required. Files can also be opened directly, although an HTTP server is recommended for preview.

## Experience

- A rotating, mathematical proof sphere and an editorial introduction.
- Three scroll-linked chapters: scarcity, proof of work, and ownership.
- An animated energy → computation → security diagram.
- A short monetary thesis and curated links to primary resources.
- Mobile navigation, keyboard focus states, reduced-motion support, a pause control, and content that remains accessible without JavaScript.

See [content sources](docs/content-sources.md) for source boundaries. This is an independent community explainer, not official Nockchain branding or an investment promise.
